# 🏠 Airbnb Clone

## 📌 About the Project
This is a full-stack Airbnb clone web application where users can explore
different property listings, create their own listings, and add reviews.

## ✨ Features
- User Signup and Login
- User Authentication
- Create new listings
- View listing details
- Edit and Delete listings
- Add and Delete reviews
- Session-based authentication
- Form validation
- Responsive UI
- MongoDB database integration

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap
- Node.js
- Express.js
- MongoDB
- MongoDB Atlas
- EJS
- Passport.js

## 🗄️ Database
MongoDB is used to store:
- User information
- Listing information
- Reviews

## 🔐 Authentication
Passport.js and sessions are used for user authentication and authorization.

## 📂 Project Structure
- `models/` → Database models
- `routes/` → Application routes
- `views/` → EJS templates
- `public/` → CSS and JavaScript files
- `middleware/` → Custom middleware
- `app.js` → Main application file

## 🚀 Installation

1. Clone the repository
2. Install dependencies:
   `npm install`
3. Create a `.env` file and add required environment variables.
4. Start the server:
   `node app.js`
5. Open the application in your browser.
